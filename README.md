In this Project we are mainly focusing on the task of performing translation from one language (Russian) to 
another (English) using sequence-to-sequence encoder-decoder architecture with GRUs. We preprocess data to 
extract tokens or words from the data by removing punctuation and converting all letters to lowercase for both the 
languages (Russian and English). We map the words into vectors for both the languages using the Continuous Bag Of 
Words Model (CBOW model) for both the languages and we choose a word in each language and show the nearest 
words to the word using Principal Component Analysis (PCA).
